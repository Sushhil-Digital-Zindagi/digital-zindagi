# Digital Zindagi

A premium, mobile-first super-app for India — multi-vendor marketplace, recharge business, earning portal, chat, games, and more. Built on the Internet Computer with stable 25GB canister storage.

## Features

- Mobile-first PWA with dark/light mode
- Multi-vendor marketplace with provider registration and approval
- Mobile recharge system with wallet and commission engine
- Offer earning portal with 60/40 profit split
- Ludo game ecosystem with rewards wallet
- Udhaar Book (credit ledger) for providers
- Likeup chat module (WhatsApp-style messaging)
- Dynamic custom sections and code injection from Admin Panel
- Video gallery with multi-platform support
- Sarkari jobs and news feed
- Student tools: image resizer, AI enhancer, age & percentage calculators
- Payment gateway control (Razorpay, UPI, QR)
- 5-tier MLM referral system
- Full admin control panel (hidden via 5-tap gesture)

## Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, TanStack Router, React Query
- **Backend:** Motoko canister (Internet Computer)
- **Canister ID:** qoab5-iyaaa-aaaad-aggsq-cai (25GB stable storage)
- **Media:** Cloudinary (cloud: dquyiiu7o)

## Getting Started

```bash
# Install dependencies
pnpm install

# Type check
pnpm typecheck

# Build
pnpm build
```
